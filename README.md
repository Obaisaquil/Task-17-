# Division Using Promise

## Description
This project performs division of two numbers entered by the user.

## Features
- Uses arrow functions
- Uses JavaScript Promise
- Handles division by zero
- Uses `throw` and `reject()`
- Uses `async/await`
- Uses `try...catch` for error handling

## How It Works
The user enters two numbers using `prompt()`. The first number is divided by the second number. If the second number is `0`, an error message is displayed.

- HTML
